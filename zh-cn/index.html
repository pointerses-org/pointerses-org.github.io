PointerSes

开源 · 免费 · 强大

PointerSes 是一个系统级编程语言，语言风格与 Groovy-DSL 相近。
基于 Rust 与 Zig 实现，支持原生打包二进制文件，依赖管理只需一个 URL。

查看源码

关于 PointerSes

Groovy-DSL 风格

如果你熟悉 Gradle (Groovy-DSL) 项目开发，可以快速转型投入 PointerSes 项目开发，学习曲线平缓。

Rust + Zig 双内核

基于 Rust 与 Zig 构建，兼顾安全性与跨架构能力，强大且轻量。

Daemon 快速拉起

支持通过 Daemon 进程快速拉起 PointerSes 实例，极大降低启动开销。

核心特性

⚙️

强大的工具链

语言原生支持打包二进制文件（exe 及 Unix 软件），无需额外配置即可产出可执行文件。

📦

YAML 项目配置

通过 YAML 格式轻松配置项目，简洁直观，告别繁琐的配置文件。

🌐

URL 直接导入依赖

无需坐标，直接写一个 https:// 地址即可导入库，跨平台通用，简单直接。

🧵

自动化与手动并存

直接通过一行代码切换自动化线程管理与手动化管理。上限高，下限低，灵活掌控并发。

🖥️

跨架构编译

搭配 Zig 实现跨架构支持，一次编写，多平台编译。

🔓
