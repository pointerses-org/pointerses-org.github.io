PointerSes

開源 · 免費 · 強大

PointerSes 是一個系統級程式語言，語言風格與 Groovy-DSL 相近。
基於 Rust 與 Zig 實現，支援原生打包二進位檔案，依賴管理只需一個 URL。

關於 PointerSes

Groovy-DSL 風格

如果你熟悉 Gradle (Groovy-DSL) 專案開發，可以快速轉型投入 PointerSes 專案開發，學習曲線平緩。

Rust + Zig 雙核心

基於 Rust 與 Zig 構建，兼顧安全性與跨架構能力，強大且輕量。

Daemon 快速拉起

支援透過 Daemon 行程快速拉起 PointerSes 實例，大幅降低啟動開銷。

核心特性

⚙️

強大的工具鏈

語言原生支援打包二進位檔案（exe 及 Unix 軟體），無需額外設定即可產出可執行檔案。

📦

YAML 專案設定

透過 YAML 格式輕鬆設定專案，簡潔直觀，告別繁瑣的設定檔。

🌐

URL 直接匯入依賴

無需座標，直接寫一個 https:// 地址即可匯入函式庫，跨平台通用，簡單直接。

🧵

自動化與手動並存

直接透過一行程式碼切換自動化執行緒管理與手動化管理。上限高，下限低，靈活掌控並行。

🖥️

跨架構編譯

搭配 Zig 實現跨架構支援，一次編寫，多平台編譯。

🔓
