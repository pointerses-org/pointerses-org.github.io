PointerSes

Open Source · Free · Powerful

PointerSes is a system-level programming language with a Groovy-DSL style.
Built on Rust and Zig, supports native binary packaging and dependency import via URL.

View Source

About PointerSes

Groovy-DSL Style

If you are familiar with Gradle (Groovy-DSL) development, you can quickly transition to PointerSes with a gentle learning curve.

Rust + Zig Dual Core

Built with Rust and Zig, combining safety and cross-architecture capabilities, powerful yet lightweight.

Daemon Fast Launch

Supports quick launching of PointerSes instances via a daemon process, greatly reducing startup overhead.

Core Features

⚙️

Powerful Toolchain

Native support for packaging binary files (exe and Unix software) without extra configuration.

📦

YAML Project Configuration

Easily configure projects using YAML format, concise and intuitive.

🌐

URL Dependency Import

No coordinates needed, simply write an https:// URL to import libraries, cross-platform and straightforward.

🧵

Auto & Manual Threading

Switch between automatic and manual thread management with a single line of code. High ceiling, low floor.

🖥️

Cross-Architecture Compilation

Leverages Zig for cross-architecture support, write once, compile for multiple platforms.

🔓
